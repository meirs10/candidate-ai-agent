# Pin the OpenTelemetry family, which ChromaDB imports at module load.
#
# A fresh deploy resolved an old opentelemetry-proto whose generated _pb2
# modules use the pre-protoc-3.20 `_descriptor.FieldDescriptor(...)` style. The
# modern protobuf runtime rejects those from _CheckCalledFromGeneratedFile(),
# and the app dies at import with a TypeError that Streamlit Cloud redacts.
#
# Setting PROTOCOL_BUFFERS_PYTHON_IMPLEMENTATION=python does NOT help here:
# Streamlit imports protobuf itself before any application code runs, and
# protobuf picks its backend at its own import time. The version floor is the
# only thing that fixes it. 1.42.x is the combination running locally.
opentelemetry-api>=1.30
